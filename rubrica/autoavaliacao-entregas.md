# Autoavaliação das Entregas

Com base nos critérios de avaliação (Item 10 do Regulamento), o grupo realiza a seguinte autoavaliação:

| Critério Regulamento | Justificativa |
|---|---|
| **10.1** Organização | Cumprimos todos os prazos das Sprints 01 a 08 e mantivemos colaboração constante. |
| **10.2** Uso do Scrum | Backlog ativo via GitHub Projects, Sprints planejadas e documentadas em seus respectivos arquivos. |
| **10.3 / 10.4** Qualidade e Conceitos | A aplicação atende aos requisitos propostos; utilizamos Padrões de Projeto (Factory, Observer) e arquitetura MVC. |
| **10.5** Documentação | O repositório está estruturado 100% de acordo com os Apêndices A e B do regulamento. |
| **10.6** Evolução Incremental | A aplicação foi evoluída gradualmente, passando do levantamento de requisitos até o deploy e validação final na Sprint 08. |
| **10.7** Uso do GitHub | O histórico conta com commits dos membros |
| **10.8** Adequação Web | A solução é uma aplicação Web funcional (Cliente-Servidor com API REST), operando corretamente no navegador. |
| **10.9** Apresentação Final | A exposição demonstrou o domínio do grupo sobre o código, a arquitetura e o sistema em funcionamento|
