# Critérios de Avaliação Interna do Grupo

A equipe estipulou os seguintes critérios para avaliar o engajamento interno durante as Sprints:
1. **Assiduidade:** Participação nas reuniões de planejamento (Plannings) e revisões.
2. **Entregas:** Cumprimento dos prazos das *issues* assumidas por cada membro.
3. **Qualidade:** Código e documentação entregues sem necessidade de grande refatoração por outros membros.
