# Visão Geral do Projeto

O Sistema de Gestão de Estoque é uma aplicação Web desenvolvida para modernizar, centralizar e tornar seguro o processo de logística e vendas de lojas físicas. O objetivo é substituir controles manuais ou planilhas desorganizadas por uma plataforma digital eficiente.

O sistema atende a três perfis principais:
1. **Administrador (Master):** Gestão irrestrita e controle de segurança e usuários.
2. **Gerente:** Cadastro de produtos, reposição e monitoramento de alertas de escassez.
3. **Vendedor/Operador:** Consulta rápida de produtos e registro de vendas com baixa automática no estoque.
