# Modelagem do Sistema

Ao longo da Sprint 03, foram desenvolvidos diagramas essenciais para o entendimento das regras e estrutura do sistema. As imagens encontram-se na pasta `docs/diagramas`.

* **Casos de Uso:** Mapeamento das interações dos atores (Admin, Gerente e Vendedor) com o sistema. [Visualizar](../diagramas/casos-de-uso.png)
* **Diagrama de Classes:** Estrutura orientada a objetos (Produto, Usuario, Venda). [Visualizar](../diagramas/classes.png)
* **Modelo de Dados (MER):** Estrutura das tabelas no banco de dados SQLite. [Visualizar](../diagramas/modelo-dados.png)
* **Diagrama de Sequência (Venda):** Fluxo temporal da rotina de baixa de estoque. [Visualizar](../diagramas/sequencia-venda.png)
